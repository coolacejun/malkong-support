말콩 개인정보처리방침

시행일: 2026년 10월 18일

운영자 noriddori-jpg는 말콩 Android 앱의 정보 처리 방식을 아래와 같이 안내합니다. 이 방침은 Android 앱 0.1.1의 공개 명언 조회와 기기 내 기록 기능에 적용됩니다. 별도의 관리자 웹과 웹 사용자 앱에는 적용되지 않습니다.

1. 기기에 저장하는 정보

앱은 선택한 기분, 날짜별 카드, 저장한 명언, 열람 기록, 설정을 기기의 앱 저장 공간에 보관합니다. 이 Android 버전은 이러한 사용자 기록을 운영자의 서버나 Firebase 사용자 기록 저장소에 전송하거나 동기화하지 않습니다. 회원가입이나 로그인이 필요하지 않습니다.

2. 인터넷 연결과 외부 서비스

앱은 Google Cloud Firestore에서 공개 명언 목록을 HTTPS로 읽습니다. 이 요청에는 기분 기록이나 저장 목록을 포함하지 않습니다. 인터넷 통신 과정에서 서비스 제공자에게 IP 주소 등 연결 정보가 전달될 수 있습니다.

YouTube 영상, 미리보기 이미지, 외부 기사 등 원문 출처를 이용하면 해당 서비스에 연결됩니다. 외부 서비스는 IP 주소, 기기·브라우저 정보, 쿠키 등을 자체 정책에 따라 처리할 수 있습니다. Google 개인정보처리방침을 확인할 수 있으며, 다른 출처의 정책은 해당 사이트에서 확인할 수 있습니다.

3. 광고와 분석

이 Android 버전은 광고 SDK, Firebase Analytics, Crashlytics를 사용하지 않습니다. 기분 기록이나 저장 목록을 광고 목적으로 판매하거나 제공하지 않습니다.

4. 보관과 삭제

기기 내 기록은 앱에서 해당 기록을 삭제하거나 Android 설정에서 앱 데이터를 삭제하거나 앱을 제거할 때까지 보관됩니다. 앱의 기록 삭제 기능을 사용할 수 있습니다. 앱 데이터 삭제와 앱 제거 시 기록을 복원하지 못할 수 있습니다.

사용자가 직접 다른 앱으로 내용을 공유하면 선택한 공유 대상에 그 내용이 전달됩니다. 공유 대상의 정보 처리는 해당 서비스의 정책을 따릅니다.

5. 문의

오류 제보와 개인정보 관련 요청은 말콩 지원 게시판에서 접수합니다. 공개 게시판에는 개인정보, 기분 기록, 백업 파일, 로그인 정보를 게시하지 마세요. 문의 내용과 GitHub 계정 정보는 GitHub 정책에 따라 처리됩니다.

6. 이용 연령

앱은 만 13세 이상을 대상으로 준비합니다. 운영자는 이 Android 버전에서 아동의 계정이나 개인정보를 수집하는 가입 기능을 제공하지 않습니다.

7. 변경 안내

로그인, 클라우드 기록 동기화, 분석 등 정보 처리 방식이 변경되면 이 문서를 수정하고 시행일과 적용 범위를 안내합니다.
